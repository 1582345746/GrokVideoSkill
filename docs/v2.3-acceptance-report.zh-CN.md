# v2.3.0 发布验收报告

验收日期：2026-09-01。`F:\AI视频数据库` 只用于本机外部基准，源图片和视频没有复制到仓库，`acceptance/` 由 Git 忽略。凭据继续只从当前用户的 Windows DPAPI 配置读取；源码、命令输出、报告和提交均不保存 Key。

## 外部视觉基准

- 数据库只读盘点：133 张图片、58 条视频，分为图片/视频下的 `真人`、`动漫`、`动画` 六个组合。
- 按稳定相对路径哈希从每组抽取 3 例，共 18 例；图片检查 1 张证据帧，视频检查 3 个内部时间点。
- 18/18 已生成哈希绑定审核回执，pending=0，弱标签约束通过 18/18。
- 近真人动漫图片和视频均记录为 `human-like-fictional`，包括 `medium=photoreal`、`realism=high` 的案例；没有误记为 `real-person`。
- `真人` 目录中的 AI 写实人物记录为 `synthetic-human`；同时出现写实人物和 CG 生物的 AIGC 剧集记录为 `hybrid + mixed`。目录名没有被当作实际人物来源证明。
- 重复运行基准恢复相同 manifest 和回执，18/18 仍有效；篡改证据帧的自动测试会使回执失效。

本机报告位于 `acceptance/v2.3/visual-benchmark/benchmark-report.json`，不进入发布包或 Git。

## 编辑 v2 验收

真实 FFmpeg 集成测试覆盖：

- 单镜头 2.0 倍和 0.5 倍速度，视频 PTS、音频 atempo 与输出时长一致。
- `monochrome`、`sharpen` 等逐镜头滤镜和全局滤镜可组合。
- 同一三镜头时间线先硬切、后 dissolve；连续硬切编组后跨组转场无时间基错误。
- -14 LUFS 与默认 -16 LUFS 计划均完成渲染；`--no-normalize` 合同可显式关闭。
- 输出开始、边界和结束预览帧，路径与 SHA-256 写入 `edit-state.json`。
- v1 edit-plan 在不修改源 JSON 的前提下迁移为 v2 语义并完成渲染。
- 相同计划恢复已有输出；干净母版路径与编辑母版路径保持分离。

## 外部后端

- 当前任务工具枚举没有 ChatCut/Jianying MCP 工具，未伪造 ChatCut 调用或登录状态；交接包和回执门禁保持有效。
- 本机剪映检测结果仍为版本耦合 opaque payload，未发现稳定、公开、可跨用户验证的草稿接口；没有生成假的 `draft_content.json`，也没有写用户剪映目录。
- `auto` 的确定性后端仍为原生 FFmpeg。
