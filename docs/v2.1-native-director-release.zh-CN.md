# v2.1.0 native-director 发布与验收说明

日期：2026-08-30

## 这次版本解决什么

v2.1 把“导演规划 + 上游原生音频 + 有效片段剪辑 + 表演 QA”提升为所有视频路线共用的核心层。它适用于 T2V、I2V、用户现成图片动画、微电影/短剧、广告、表演、新闻和连续剧；连续剧在此之上才增加季级连续性和逐集审批。

默认合同如下：

- 视频上游默认 QuickAI；用户说“生视频选择 QuickAI New”时固定 QuickAI New，T2V/I2V 都不先调用 QuickAI。
- 新项目 `audio.mode=native-dialogue`、`generate_audio=true`、`subtitle_source=none`。QuickAI 的音频是模型默认能力，QuickAI New 使用显式音频字段；两者都必须人工听审。
- 新项目 `frame_layout=single-full-frame`、`allow_multi_panel=false`。分屏、三联画、漫画格必须由具体镜头显式开启。
- 竖屏、多人、T2V、单画面组合默认在付费前阻断，建议先审核单画面关键帧，再用 I2V。显式 `layout_risk_policy=allow` 只表示用户接受风险，不代表上游会稳定输出单画面。
- 生图、生视频和角色母版共用三次总尝试预算；备用上游计入次数；`submission_unknown` 不自动重建。
- 提示词按 UTF-8 字节计数，硬上限 4096、工作上限 3800，保留完整/精简/最小三版，禁止静默截断。

### 上游 A/B 观察

QuickAI 和 QuickAI New 的单镜头竖屏双人 T2V 都曾返回重复的 2 至 3 格画面；改写提示词或切换视频上游不能稳定消除该问题。使用一张已审核的单画面关键帧走 QuickAI I2V 得到单一完整画面和原生音频。因此布局门禁是产品规则，不是某个提示词的偶然技巧。

## 模块专项验收

专项项目目录以 `full/module-*` 命名，覆盖：

- T2V、I2V、用户现成图、角色母版/关键帧；
- `cinematic-short`、`dialogue-scene`、`silent-cinema`、`action-scene`、`comedy-scene`；
- 产品广告、人物表演、插画/风景动效、短剧、连续剧；
- sourced news 和显式 `upstream` 字幕。

明确含分屏、内嵌字幕或人物身份漂移的候选素材保留在原项目并标记为 rejected/needs review，不会被包装成“通过”。通过的模块交付文件仍需人工观片和听审；技术 QA 只证明媒体可读、方向/编码/音轨和布局信号符合合同。

“通过”表示该路线至少有一个经过人工画面/听审的可交付样片，不表示所有提示词、人物或题材都能稳定复现同一质量。失败样片和替换记录留在本机验收目录中，便于继续二开。

## 未宣称的能力

当前两个网关不提供 MP4 视频参考、视频编辑/延展、预设音色参考或用户 WAV 参考。预检会阻断这些输入，未来应分别实现 `video-edit`、`video-extend`、`preset_voice_reference` 和 `audio_file_reference`，不能把它们塞进普通 I2V 字段。原生对白、音色、逐字内容、口型和模型内嵌字幕仍是生成式结果，不能承诺完全准确。
